# DreamHouse game code

- **Glade (jMonkeyEngine):** run `CHOI-GAME.cmd` to open the bundled game, or run `Mo-DreamHouse-Glade.cmd`. Developers can rebuild with `Build-DreamHouse.ps1`.
- **Classic (JavaFX):** run `Mo-DreamHouse-Classic.cmd` from Windows. The Maven project is in `classic`.
- The `glade` and `classic` folders contain source projects. Build output and player data are not included here except for the current portable Glade release required to run without a JDK.
